# Ohara interface direction

The user chose a compact library index: search and records first, with the existing navigation.

Reading this as a reference catalogue for developers and formal-methods contributors. ENERGY 1 / RHYTHM 2 / MOTION 1.

- Put the real catalogue on the home page. Keep guides in Starlight's existing navigation rather than introducing another navigation system.
- Use paper and ink neutrals with a forest-green accent for the current location and focus. Keep Starlight's working system, light and dark choices.
- Use a small Georgia heading as the library's typographic identity, system sans for reading and controls, and monospace only for actual symbols, code and source identifiers.
- Use ruled record rows, with the statement and summary before the separate evidence dimensions. The rows are entries, not feature cards.
- Keep search close to its results. Use wider gaps between different tasks and smaller gaps within each record.
- Show the exact theorem statement where it exists. Keep sources, assumptions, licensing and evidence scope intact.
- List formal statements before project overviews. Render the catalogue title's dash separator as a colon without editing the immutable source records.
- Use no decorative imagery, icons, badges or motion. Existing search, theme and navigation icons retain their functional meaning.
- Static records arrive with the HTML. Empty filtering has a reset action; the existing document-search component handles its asynchronous states.
- Keep contents links on guides with real sections. Remove the empty Overview-only pane from record and operations pages.
- Give search, menu and theme controls 44px touch targets. Keep the menu flat and reserve its width in the mobile header so the controls stay separate.
- Serve Astro's existing 404 page for missing paths so visitors get a working route back to the catalogue.

Copy names the thing or action directly. Catalogue acceptance, a mechanical check, human review and correspondence to caller code remain separate claims. No customer, trust or verification claim is added.
